# Home library

A catalog for a family's children's books, in Japanese, Czech and English, that knows where every book is: on which shelf or in which box.

Most books are meant to enter the catalog from phone photos read by a vision-capable LLM. An agent harness such as Claude Code or Codex does the reading and the look-ups, and later helps plan seasonal rotations.

## Status

Planning. Nothing is built yet. As of 2026-10-05 the requirements are settled and the design is a draft with open decisions.

They were drafted with AI assistance (Claude Code) from planning conversations with the family. The research notes state their own provenance, and mark what was observed, what is only documented, and what is unverified.
