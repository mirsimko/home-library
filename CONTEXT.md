# Home library

The family's system for knowing which children's books it owns and where each one is.

## Language

**Active**:
A book on a shelf the children can reach.
_Avoid_: In use, current

**Stored**:
A book boxed away that stays in the family and is expected to come back, such as a seasonal book or one waiting for the younger child.
_Avoid_: Archived, put away

**Retired**:
A book that is still at home but set aside for resale or give-away.
_Avoid_: Discarded, archived

**Location**:
The shelf or box where a book physically is. Every Active, Stored and Retired book has one.
_Avoid_: Place, position
